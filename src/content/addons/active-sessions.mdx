## What it does

Where the core plugin's Force Logout is single-user and all-or-nothing,
**Active Sessions** gives you a discoverable, operational view of who is
signed in across your site right now. It adds a **Sessions** tab to the
Loggedin admin with one row per user — sortable and searchable — showing
their active session count, last login, and last IP.

Open any user to see each of their sessions individually: the device,
the IP it started from, when it signed in, and when it expires. Sign out
a single device, end every session for that user, or select multiple
users and clear them all in one action.

## Who it's for

Membership sites, LMS courses, and any install where an admin needs to
answer "who's logged in right now?" — and act on the answer. Pair it with
[Real-time Logout](/software/plugins/loggedin/realtime-logout) so a
sign-out takes effect on the user's open tabs almost immediately.
