## What it does

Without it, a browser tab that has already been logged out elsewhere keeps
rendering as if authenticated until the user clicks something. **Real-time
Logout** closes that gap: a small script polls the server on a fixed
interval, and the moment the session is gone — a logout elsewhere, an admin
force-logout, or a hit concurrent-session limit — the tab hard-reloads back
to wp-login.

## How it works

Despite the name, this isn't WebSockets or push — it's deliberate polling,
because polling works on every WordPress host with no sidecar service or
firewall changes. At the recommended 60-second interval the load is
negligible, and the script is only shipped to logged-in users.

It adds a **Real-time Logout** panel to the Loggedin settings tab where you
set the refresh interval. Best paired with
[Active Sessions](/software/plugins/loggedin/active-sessions) so an admin
sign-out is both easy to trigger and quick to land.
