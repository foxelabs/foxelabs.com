## What it does

Freemius Plugin Licensing is a slim alternative to the full Freemius SDK: it talks
to the Freemius API directly to handle license activation, deactivation, update
delivery, and add-on listing — and nothing else. There's no bundled admin UI, so
you stay in control of how licensing looks and behaves in your plugin.

## Why it exists

The official SDK ships a lot of UI and opinion along with the licensing logic. When
you only need the licensing plumbing — and want to design the experience yourself —
this library gives you just that, keeping your plugin lean.

Install with Composer:

```bash
composer require duckdev/freemius-plugin-licensing
```
