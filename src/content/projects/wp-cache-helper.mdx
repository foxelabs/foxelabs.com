## What it does

WP Cache Helper wraps the WordPress object cache and transients behind one small,
consistent API — with grouped invalidation, prefixed keys, and a driver layer you
can swap out in tests.

Install with Composer:

```bash
composer require duckdev/wp-cache-helper
```
