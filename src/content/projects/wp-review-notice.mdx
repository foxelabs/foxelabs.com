## What it does

WP Review Notice asks plugin users for a WordPress.org review once they've
actually used the plugin for a while — never on day one. It's built to be
testable and DI-friendly, with swappable storage for the notice state.

Install with Composer:

```bash
composer require duckdev/wp-review-notice
```
