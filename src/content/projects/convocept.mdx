## What it does

Convocept swaps the theme's comment section for a fast, server-rendered thread:
threaded replies, upvotes, pinned comments, email subscriptions, spam
protection and moderation in place. It loads no JavaScript until a reader
reaches the comments, and it keeps every comment in the native WordPress
tables, so Akismet, backups and the Comments screen keep working.

## Learn more

Convocept has its own home at [convocept.com](https://convocept.com), with the
full feature list, comparisons with Disqus, wpDiscuz and default WordPress
comments, and migration guides. It is free on
[WordPress.org](https://wordpress.org/plugins/convocept/).
